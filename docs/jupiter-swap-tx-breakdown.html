20-swap v0 + ALT Jupiter batch transaction

A deterministic 690-byte serialized transaction that executes one compute-budget instruction and one compact batch instruction. The batch instruction carries twenty swap records and CPIs into the mock Jupiter program inside LiteSVM.

The transaction is below the 1,232-byte packet cap. The next swap fails because the mock route reaches 2 + 3n runtime trace entries: one compute-budget ix, one batch ix, one Jupiter CPI per swap, and two SPL Token CPIs per swap.

At 20 swaps the trace length is 62. At 21 swaps it becomes 65 and fails with MaxInstructionTraceLengthExceeded.
